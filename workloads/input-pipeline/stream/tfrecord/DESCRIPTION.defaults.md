## In brief

tf.data over TFRecord shards: cycle shards streamed concurrently, positioned reads of the buffer size to EOF. In the catalog it is `input-pipeline/stream/tfrecord`: application `tf-data`, format `tfrecord`, phase training, domain ai. No case yet: the abstract at its defaults, at 1 GPU. `shards` holds 1,281,167 samples, 1,024 a file (148.8 GiB in 1,252 files), consumed shard by shard in a keyed shuffle; sizes lognormal, median 110 KiB, σ 0.45 (5th–95th percentile 52.5 KiB to 230.6 KiB). The one `gpu` actor (one per GPU): 4 loader workers build 125 batches, up to 1 ahead each; per batch, on the next shard of `shards`, open, read in 256 KiB requests at an offset to end of file, close; in phase `train`, 500 times: when `(step mod (samples_per_file div batch)) = 0`, take a batch from `shards`; compute for 105 ms; a barrier with every GPU. Measured by dry run at 1 GPU (61,308 ops: 61,058 read, 125 close, 125 open; 14.9 GiB read, nothing written): read runs: large (112 MiB); read requests: small (256 KiB); share of bytes read: read-only (100%); metadata ops per data op: none (0.00409); reads its own writes: no; share of block reads that are re-reads: none (0%); share of accesses to the hottest 1% of blocks: uniform (1%).

### The `gpu` actor (1 instance, one per GPU)

- A loader `shards`: 4 (`cycle`) workers, worker w building batches w, w + W, …, each up to 1 (`prefetch`) batches ahead; 125 (`⌈steps × batch / samples_per_file⌉`) batches in all, delivered in batch order. For batch `b`:
  - `s` is the next shard (a whole file) of `shards` from the shuffle, without replacement.
  - `open` `s` (RDONLY).
  - `read` `s`: requests of 256 KiB (`xfer`) at offset 0 bytes until end of file, the short or empty last one included.
  - `close` `s`.
  - Computes for 0 ns (`decode`), no I/O.
- Phase `train`:
  - 500 times (`steps`), `step` = 0 to 499:
    - If `(step mod (samples_per_file div batch)) = 0`:
      - Takes the next batch from the loader `shards`.
    - Computes for 105 ms (`step_time`), no I/O.
    - If `(step mod sync_every) = 0` (true here):
      - Waits at a barrier with every actor on every host.
