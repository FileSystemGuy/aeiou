## In brief

np.load of one ~140 MiB .npz per sample through a PyTorch DataLoader; magic, zip tail, then the archive front to back. In the catalog it is `input-pipeline/map/npy-per-sample`: application `numpy`, format `npz`, phase training, domain ai. An example case (`npy-8mib`: volume data), its parameters holding at 1 GPU. Traced: a capture is within the tolerances. `train` holds 256 samples, one a file (2.0 GiB in 256 files), consumed in a keyed shuffle without replacement; sizes normal, mean 8 MiB, standard deviation 256 KiB (5th–95th percentile 7.6 MiB to 8.4 MiB), clamped to at least 1 MiB. The one `gpu` actor (one per GPU): in phase `walk`, for each of the 1 directories of `train`: on a directory of `train`, open, fstat, readdir to the end, close; 2 loader workers build 128 batches, up to 2 ahead each; per batch, 4 times: on the next sample of `train`, open, fstat, ioctl TCGETS, lseek, read 1 MiB, lseek 3 times, read 1 MiB, lseek, read 1 MiB, lseek, read 1 MiB, lseek; for each `k` below `⌈(size(f) − framing) / np_chunk⌉ div (xfer div np_chunk)`: read 1 MiB; 4 times: lseek; for each `rep` below `⌈size(f) / xfer⌉ − (⌈(size(f) − framing) / np_chunk⌉ div (xfer div np_chunk))`: read 1 MiB; for each `t` below `(⌈(size(f) − framing) / np_chunk⌉ mod (xfer div np_chunk)) + 4`: lseek; close; in phase `train`, 128 times: take a batch from `batches`; compute for 323 ms; a barrier with every GPU. Measured by dry run at 1 GPU (30,698 ops: 22,248 lseek, 6,398 read, 513 close, 513 fstat, 513 open, 512 ioctl, 1 readdir; 4.5 GiB read, nothing written): read runs: medium (7 MiB); read requests: medium (1 MiB); share of bytes read: read-only (100%); metadata ops per data op: low (0.241); reads its own writes: no; share of block reads that are re-reads: repeated (55.6%); share of accesses to the hottest 1% of blocks: uniform (1.86%).

### The `gpu` actor (1 instance, one per GPU)

- If `walk` (true here):
  - Phase `walk`:
    - For each of the 1 directories `d` of `train`:
      - `dh` is directory `d` of `train`.
      - `open` `dh` (RDONLY|CLOEXEC|DIRECTORY).
      - `fstat` `dh`.
      - `readdir` `dh` to the end.
      - `close` `dh`.
- If `inventory` (false here: skipped):
  - Phase `inventory`:
    - `inv` is the inventory of `train`.
    - `open` `inv` (RDONLY|CLOEXEC).
    - `fstat` `inv`.
    - `ioctl` `inv` `TCGETS` (may fail with ENOTTY).
    - `lseek` `inv` to 0 from the current position.
    - `read` `inv`: requests of 1 MiB (`inv_read`) at the file position until end of file, the short or empty last one included.
    - `close` `inv`.
- A loader `batches`: 2 (`workers`) workers, worker w building batches w, w + W, …, each up to 2 (`prefetch`) batches ahead; 128 (`steps`) batches in all, delivered in batch order. For batch `b`:
  - 4 times (`batch`), `j` = 0 to 3:
    - `f` is the next sample of `train` from the shuffle, without replacement.
    - `open` `f` (RDONLY|CLOEXEC).
    - `fstat` `f`.
    - `ioctl` `f` `TCGETS` (may fail with ENOTTY).
    - `lseek` `f` to 0 from the current position.
    - `read` `f`: 1 MiB (`hdr_read`) at the file position.
    - `lseek` `f` to 0 from the end.
    - `lseek` `f` to 0 from the current position.
    - `lseek` `f` to -22 bytes from the end.
    - `read` `f`: 1 MiB (`hdr_read`) at the file position.
    - `lseek` `f` to `size(f) − 22 − 20` from the start.
    - `read` `f`: 1 MiB (`hdr_read`) at the file position.
    - `lseek` `f` to `size(f) − 22 − cd_len` from the start.
    - `read` `f`: 1 MiB (`hdr_read`) at the file position.
    - `lseek` `f` to 0 from the start.
    - For `k` from 0 while below `⌈(size(f) − framing) / np_chunk⌉ div (xfer div np_chunk)`:
      - `read` `f`: 1 MiB (`xfer`) at the file position.
      - 4 times (`xfer div np_chunk`), `t` = 0 to 3:
        - `lseek` `f` to 0 from the current position.
    - For `rep` from 0 while below `⌈size(f) / xfer⌉ − (⌈(size(f) − framing) / np_chunk⌉ div (xfer div np_chunk))`:
      - `read` `f`: 1 MiB (`xfer`) at the file position.
    - For `t` from 0 while below `(⌈(size(f) − framing) / np_chunk⌉ mod (xfer div np_chunk)) + 4`:
      - `lseek` `f` to 0 from the current position.
    - `close` `f`.
- Phase `train`:
  - 128 times (`steps`), `step` = 0 to 127:
    - Takes the next batch from the loader `batches`.
    - Computes for 323 ms (`step_time`), no I/O.
    - If `(step mod sync_every) = 0` (true here):
      - Waits at a barrier with every actor on every host.
