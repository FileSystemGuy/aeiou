## In brief

np.load of one ~140 MiB .npz per sample through a PyTorch DataLoader; magic, zip tail, then the archive front to back. In the catalog it is `input-pipeline/map/npy-per-sample`: application `numpy`, format `npz`, phase training, domain ai. A use case (`unet3d-a100`: volume data, a vision model), its parameters holding at 1 GPU. Not traced yet. `train` holds 50,000 samples, one a file (6.7 TiB in 50,000 files and 5 directories), consumed in a keyed shuffle without replacement; sizes normal, mean 139.8 MiB, standard deviation 65.2 MiB (5th–95th percentile 32.6 MiB to 247.0 MiB), clamped to at least 1 MiB. The one `gpu` actor (one per GPU): in phase `walk`, for each of the 5 directories of `train`: on a directory of `train`, open, fstat, readdir to the end, close; 4 loader workers build 500 batches, up to 2 ahead each; per batch, 7 times: on the next sample of `train`, open, fstat, ioctl TCGETS, lseek, read 1 MiB, lseek 3 times, read 1 MiB, lseek, read 1 MiB, lseek, read 1 MiB, lseek; for each `k` below `⌈(size(f) − framing) / np_chunk⌉ div (xfer div np_chunk)`: read 1 MiB; 4 times: lseek; for each `rep` below `⌈size(f) / xfer⌉ − (⌈(size(f) − framing) / np_chunk⌉ div (xfer div np_chunk))`: read 1 MiB; for each `t` below `(⌈(size(f) − framing) / np_chunk⌉ mod (xfer div np_chunk)) + 4`: lseek; close; in phase `train`, 500 times: take a batch from `batches`; compute for 636 ms; a barrier with every GPU. Measured by dry run at 1 GPU (2,520,800 ops: 2,000,906 lseek, 505,874 read, 3,505 close, 3,505 fstat, 3,505 open, 3,500 ioctl, 5 readdir; 482.1 GiB read, nothing written): read runs: large (160 MiB); read requests: medium (1 MiB); share of bytes read: read-only (100%); metadata ops per data op: low (0.0208); reads its own writes: no; share of bytes read that are re-reads: none (0.709%); share of accessed bytes on the most accessed 1% of bytes: uniform (1.7%).

### The `gpu` actor (1 instance, one per GPU)

- If `walk` (true here):
  - Phase `walk`:
    - For each of the 5 directories `d` of `train`:
      - `dh` is directory `d` of `train`.
      - `open` `dh` (RDONLY|CLOEXEC|DIRECTORY).
      - `fstat` `dh`.
      - `readdir` `dh` to the end.
      - `close` `dh`.
- If `inventory` (false here: skipped):
  - Phase `inventory`:
    - `inv` is the inventory of `train`.
    - `open` `inv` (RDONLY|CLOEXEC).
    - `fstat` `inv`.
    - `ioctl` `inv` `TCGETS` (may fail with ENOTTY).
    - `lseek` `inv` to 0 from the current position.
    - `read` `inv`: requests of 1 MiB (`inv_read`) at the file position until end of file, the short or empty last one included.
    - `close` `inv`.
- A loader `batches`: 4 (`workers`) workers, worker w building batches w, w + W, …, each up to 2 (`prefetch`) batches ahead; 500 (`steps`) batches in all, delivered in batch order. For batch `b`:
  - 7 times (`batch`), `j` = 0 to 6:
    - `f` is the next sample of `train` from the shuffle, without replacement.
    - `open` `f` (RDONLY|CLOEXEC).
    - `fstat` `f`.
    - `ioctl` `f` `TCGETS` (may fail with ENOTTY).
    - `lseek` `f` to 0 from the current position.
    - `read` `f`: 1 MiB (`hdr_read`) at the file position.
    - `lseek` `f` to 0 from the end.
    - `lseek` `f` to 0 from the current position.
    - `lseek` `f` to -22 bytes from the end.
    - `read` `f`: 1 MiB (`hdr_read`) at the file position.
    - `lseek` `f` to `size(f) − 22 − 20` from the start.
    - `read` `f`: 1 MiB (`hdr_read`) at the file position.
    - `lseek` `f` to `size(f) − 22 − cd_len` from the start.
    - `read` `f`: 1 MiB (`hdr_read`) at the file position.
    - `lseek` `f` to 0 from the start.
    - If `xfer ≥ np_chunk` (true here):
      - For `k` from 0 while below `⌈(size(f) − framing) / np_chunk⌉ div (xfer div np_chunk)`:
        - `read` `f`: 1 MiB (`xfer`) at the file position.
        - 4 times (`xfer div np_chunk`), `t` = 0 to 3:
          - `lseek` `f` to 0 from the current position.
      - For `rep` from 0 while below `⌈size(f) / xfer⌉ − (⌈(size(f) − framing) / np_chunk⌉ div (xfer div np_chunk))`:

      - `read` `f`: 1 MiB (`xfer`) at the file position.
      - 3 times, `t` = 0 to 2:
        - `lseek` `f` to 0 from the current position.
      - `read` `f`: 1 MiB (`xfer`) at the file position.
