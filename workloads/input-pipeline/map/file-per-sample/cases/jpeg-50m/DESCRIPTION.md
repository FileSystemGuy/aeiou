In the catalog it is `input-pipeline/map/file-per-sample`: application `pytorch-dataloader`, format `file-per-sample`, phase training, domain ai. Not yet decided between the two; the case's README says why (`jpeg-50m`: image data, a vision model), its parameters holding at 1 GPU. Not traced yet. `train` holds 50,000,000 samples, one a file (5.7 TiB in 50,000,000 files and 38,462 directories), consumed in a keyed shuffle without replacement; sizes lognormal, median 110 KiB, σ 0.45 (5th–95th percentile 52.5 KiB to 230.6 KiB). The one `gpu` actor (one per GPU): in phase `walk`, for each of the 38,462 directories of `train`: on a directory of `train`, stat, open, fstat, readdir to the end, close; 8 loader workers build 500 batches, up to 2 ahead each; per batch, 32 times: on the next sample of `train`, open, fstat, ioctl TCGETS, lseek twice, read in 1 MiB requests to end of file, close; in phase `train`, 500 times: take a batch from `batches`; compute for 105 ms; a barrier with every GPU. ### The `gpu` actor (1 instance, one per GPU)

- If `walk` (true here):
  - Phase `walk`:
    - For each of the 38,462 directories `d` of `train`:
      - `dh` is directory `d` of `train`.
      - `stat` `dh`.
      - `open` `dh` (RDONLY|CLOEXEC|DIRECTORY).
      - `fstat` `dh`.
      - `readdir` `dh` to the end.
      - `close` `dh`.
- If `inventory` (false here: skipped):
  - Phase `inventory`:
    - `inv` is the inventory of `train`.
    - `open` `inv` (RDONLY|CLOEXEC).
    - `fstat` `inv`.
    - `ioctl` `inv` `TCGETS` (may fail with ENOTTY).
    - `lseek` `inv` to 0 from the current position.
    - `read` `inv`: requests of 1 MiB (`inv_read`) at the file position until end of file, the short or empty last one included.
    - `close` `inv`.
- A loader `batches`: 8 (`workers`) workers, worker w building batches w, w + W, …, each up to 2 (`prefetch`) batches ahead; 500 (`steps`) batches in all, delivered in batch order. For batch `b`:
  - 32 times (`batch`), `j` = 0 to 31:
    - `f` is the next sample of `train` from the shuffle, without replacement.
    - `open` `f` (RDONLY|CLOEXEC).
    - `fstat` `f`.
    - `ioctl` `f` `TCGETS` (may fail with ENOTTY).
    - `lseek` `f` to 0 from the current position.
    - `lseek` `f` to 0 from the start.
    - `read` `f`: requests of 1 MiB (`hdr_read`) at the file position until end of file, the short or empty last one included.
    - `close` `f`.
- Phase `train`:
  - 500 times (`steps`), `step` = 0 to 499:
    - Takes the next batch from the loader `batches`.
    - Computes for 105 ms (`step_time`), no I/O.
    - If `(step mod sync_every) = 0` (true here):
      - Waits at a barrier with every actor on every host.
