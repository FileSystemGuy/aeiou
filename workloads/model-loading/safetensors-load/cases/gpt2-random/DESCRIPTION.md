## In brief

Every process reads every safetensors shard, touching its tensor-parallel slice of each tensor (fan-in G). In the catalog it is `model-loading/safetensors-load`: application `transformers-safetensors`, format `safetensors`, phase inference, domain ai. An example case (`gpt2-random`: model-state data, a llm model), its parameters holding at 1 GPU. Traced: captured, but the trace cannot see the data path (a mapped file). `model` holds 5 samples, one a file (625.0 MiB in 5 files), looked up by id; sizes always 125.0 MiB. `config` holds 3 samples, one a file (12 KiB in 3 files), looked up by id; sizes always 4 KiB. The one `gpu` actor (one per GPU): in phase `load`, 3 times: on a file of `config`, stat, open, fstat, ioctl TCGETS, lseek twice, fstat, read in `size(j) + 1` requests to end of file, close; 5 times: on a file of `model`, stat, open, fstat, read 8 bytes, read `hdr_len[s]`, close, open, fstat, fadvise SEQUENTIAL; 76 times: when `shard[t] = s`, when `split[t] = 'column'`, read `bytes[t] div tp` at an offset, otherwise when `split[t] = 'row'`, for each `r` below `rows[t]`: read `row_bytes[t] div tp` at an offset, otherwise read `bytes[t]` at an offset; close; a barrier with every GPU. Measured by dry run at 1 GPU (156 ops: 92 read, 16 fstat, 13 close, 13 open, 8 stat, 6 lseek, 5 fadvise, 3 ioctl; 417.3 MiB read, nothing written): read runs: large (80 MiB); read requests: medium (16 MiB); share of bytes read: read-only (100%); metadata ops per data op: medium (0.543); reads its own writes: no; share of block reads that are re-reads: none (0.0758%); share of accesses to the hottest 1% of blocks: uniform (1.07%).

### The `gpu` actor (1 instance, one per GPU)

- `rank` = 0 (`actor id mod tp`).
- Phase `load`:
  - 3 times (`configs`), `i` = 0 to 2:
    - `j` is file `i` of `config`.
    - `stat` `j`.
    - `open` `j` (RDONLY|CLOEXEC).
    - `fstat` `j`.
    - `ioctl` `j` `TCGETS` (may fail with ENOTTY).
    - `lseek` `j` to 0 from the current position.
    - `lseek` `j` to 0 from the current position.
    - `fstat` `j`.
    - `read` `j`: requests of `size(j) + 1` at the file position until end of file, the short or empty last one included.
    - `close` `j`.
  - 5 times (`shards`), `s` = 0 to 4:
    - `f` is file `s` of `model`.
    - `stat` `f`.
    - `open` `f` (RDONLY|CLOEXEC).
    - `fstat` `f`.
    - `read` `f`: 8 bytes at the file position.
    - `read` `f`: `hdr_len[s]` at the file position.
    - `close` `f`.
    - `open` `f` (RDONLY).
    - `fstat` `f`.
    - `posix_fadvise` `f` `SEQUENTIAL`, `size(f)` from 0 bytes.
    - 76 times (`len(shard)`), `t` = 0 to 75:
      - If `shard[t] = s`:
        - If `split[t] = 'column'`:
          - `read` `f`: `bytes[t] div tp` at offset `off[t] + rank × (bytes[t] div tp)`.
        - Otherwise:
          - If `split[t] = 'row'`:
            - For `r` from 0 while below `rows[t]`:
              - `read` `f`: `row_bytes[t] div tp` at offset `off[t] + r × row_bytes[t] + rank × (row_bytes[t] div tp)`.
          - Otherwise:
            - `read` `f`: `bytes[t]` at offset `off[t]`.
    - `close` `f`.
  - Waits at a barrier with every actor on every host.
