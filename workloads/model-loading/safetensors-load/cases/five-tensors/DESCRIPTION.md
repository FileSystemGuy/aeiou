## In brief

Every process reads every safetensors shard, touching its tensor-parallel slice of each tensor (fan-in G). In the catalog it is `model-loading/safetensors-load`: application `transformers-safetensors`, format `safetensors`, phase inference, domain ai. Not yet decided between the two; the case's README says why (`five-tensors`: model-state data, a llm model), its parameters holding at 2 GPUs. Not traced yet. `model` holds 2 samples, one a file (10 GiB in 2 files), looked up by id; sizes always 5 GiB. `config` holds 3 samples, one a file (12 KiB in 3 files), looked up by id; sizes always 4 KiB. Each of the 2 `gpu` actors (one per GPU): in phase `load`, 3 times: on a file of `config`, stat, open, fstat, ioctl TCGETS, lseek twice, fstat, read in `size(j) + 1` requests to end of file, close; twice: on a file of `model`, stat, open, fstat, read 8 bytes, read `hdr_len[s]`, close, open, fstat, fadvise SEQUENTIAL; 5 times: when `shard[t] = s`, when `split[t] = 'column'`, read `bytes[t] div tp` at an offset, otherwise when `split[t] = 'row'`, for each `r` below `rows[t]`: read `row_bytes[t] div tp` at an offset, otherwise read `bytes[t]` at an offset; close; a barrier with every GPU. ### The `gpu` actor (2 instances, one per GPU)

- `rank` = `actor id mod tp`.
- Phase `load`:
  - 3 times (`configs`), `i` = 0 to 2:
    - `j` is file `i` of `config`.
    - `stat` `j`.
    - `open` `j` (RDONLY|CLOEXEC).
    - `fstat` `j`.
    - `ioctl` `j` `TCGETS` (may fail with ENOTTY).
    - `lseek` `j` to 0 from the current position.
    - `lseek` `j` to 0 from the current position.
    - `fstat` `j`.
    - `read` `j`: requests of `size(j) + 1` at the file position until end of file, the short or empty last one included.
    - `close` `j`.
  - Twice (`shards`), `s` = 0 to 1:
    - `f` is file `s` of `model`.
    - `stat` `f`.
    - `open` `f` (RDONLY|CLOEXEC).
    - `fstat` `f`.
    - `read` `f`: 8 bytes at the file position.
    - `read` `f`: `hdr_len[s]` at the file position.
    - `close` `f`.
    - `open` `f` (RDONLY).
    - `fstat` `f`.
    - `posix_fadvise` `f` `SEQUENTIAL`, `size(f)` from 0 bytes.
    - 5 times (`len(shard)`), `t` = 0 to 4:
      - If `shard[t] = s`:
        - If `split[t] = 'column'`:
          - `read` `f`: `bytes[t] div tp` at offset `off[t] + rank × (bytes[t] div tp)`.
        - Otherwise:
          - If `split[t] = 'row'`:
            - For `r` from 0 while below `rows[t]`:
              - `read` `f`: `row_bytes[t] div tp` at offset `off[t] + r × row_bytes[t] + rank × (row_bytes[t] div tp)`.
          - Otherwise:
            - `read` `f`: `bytes[t]` at offset `off[t]`.
    - `close` `f`.
  - Waits at a barrier with every actor on every host.
