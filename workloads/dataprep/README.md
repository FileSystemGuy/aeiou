# `dataprep`

Generated by `aeiou-catalog write` from `workloads/attributes.toml`; never edited by hand.

Preparing data for training: curation, filtering, deduplication, shuffling, packing, tokenization, ingest.

Also searched for as: data preparation, etl, curation, preprocessing.

## Classes

- [`scan-filter`](scan-filter/): Long sequential reads of a raw corpus, a smaller sequential write: language identification, quality filters, PII scrubbing. (no mechanisms)
- [`shuffle`](shuffle/): All-to-all: wide temporary spill, many-to-many reads and writes: global shuffles, repartitioning, exact deduplication by hash. (no mechanisms)
- [`dedup-index`](dedup-index/): An index built, then random lookups against it: fuzzy and near-duplicate deduplication. (no mechanisms)
- [`repack`](repack/): Many small files into large shards or back, metadata-heavy on one side: tar and WebDataset packing, frame extraction. (no mechanisms)
- [`tokenize-pack`](tokenize-pack/): Text in, large binary token files and their index out (Megatron-style .bin and .idx). (no mechanisms)
- [`ingest`](ingest/): Many writers landing raw data, often as object PUTs: web crawls, sensor dumps. (no mechanisms)
