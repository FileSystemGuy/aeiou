## In brief

**`lmcache_shared_fs`.** One engine per actor in front of a store with no index (LMCache fs://): stat lookups, chunks written to a temporary name and renamed. In the catalog it is `kvcache/lmcache-shared-fs`: application `vllm-lmcache`, format `lmcache-chunks`, phase inference, domain ai. An example case (`sharegpt-chat`: text data, a llm model), its parameters holding at 1 GPU. Traced: captured, but rows are outside; each has its recorded reason. `sysp` holds 2 samples, stored as chunk objects (10.9 MiB in 4 files and 2 directories), looked up by id; sizes always 5.5 MiB (a lognormal clamped to it). `subp` holds 50 samples, stored as chunk objects (942.9 MiB in 338 files and 50 directories), looked up by id; sizes lognormal, median 17.6 MiB, σ 0.3 (5th–95th percentile 10.7 MiB to 28.8 MiB), clamped to at least 12 KiB and at most 1.1 GiB. It writes the objects of `kv`, each 3.0 MiB. The one `gpu` actor (one per GPU): 300 times: in phase `warm` while `r < warm`, else `serve`,, compute for `draw(think)`; when `kind = 0`, for each `q` below `sysblk`: stat; when `kind = 1`, for each `q` below `sysblk`: stat; for each `q` below `hit`: stat; when `stored > had`, stat; `nload` in parallel, each: on an object of `kv`, open, fstat, ioctl TCGETS, lseek, read 1 MiB; read 2.0 MiB; close; for each `s` below `⌈(stored − had) / (prefill_step div chunk_tokens)⌉`: compute for `prefill_per_token × min((stored − had − s × (prefill_step div chunk_tokens)) × chunk_tokens, prefill_step)`; for each `k` below `min(stored, had + (s + 1) × (prefill_step div chunk_tokens))`: on an object of `kv`, open for writing, fstat, ioctl TCGETS, lseek, write 28 bytes, write 3 MiB, close, rename; compute for `decode_per_token × out`. ### The `gpu` actor (1 instance, one per GPU)

- 1 (`concurrency`) in parallel, `slot` = 0 onward, joined at the end:
  - 300 times (`warm + requests`), `r` = 0 to 299:
    - `d` is drawn from a mixture: 19.9% none; 80.1% always 8 (`reuse`).
    - `inn` is drawn from one of 20 weighted values, median 28 tokens, 5th–95th percentile 12 tokens to 166 tokens, mean 82.7 tokens (`turn_in`).
    - `out` is drawn from one of 20 weighted values, median 245 tokens, 5th–95th percentile 17 tokens to 630 tokens, mean 298 tokens (`turn_out`).
    - `kp` is drawn from one of 20 weighted values, median 208 tokens, 5th–95th percentile 38 tokens to 3,623 tokens, mean 699 tokens (`keep`).
    - `tr` is drawn from always 0 tokens (`trim`).
    - `tn` is drawn from always 0 (`turns`).
    - `back` = `d ≠ none and d ≤ r`.
    - `more` = `back and (turns@(r − d) = 0 or turn@(r − d) + 1 < turns@(r − d))`.
    - `prior` = `(if back then max(ptoks@(r − d) + out@(r − d) − tr, 0) else 0)`.
    - `cont` = `more and (if back then sysblk@(r − d) else 0) × chunk_tokens + prior + inn + out ≤ context`.
    - `conv` = `(if cont then conv@(r − d) else draw(uniform64))`.
    - `turns` = `(if cont then turns@(r − d) else tn)`.
    - `turn` = `(if cont then turn@(r − d) + 1 else 0)`.
    - `sp` = `(if cont then sp@(r − d) else (if sys_per_slot = true then sysp[slot mod sys_prompts] else pick(sysp)))`.
    - `kd` is drawn from always 0 (`kind`).
    - `fi` is drawn from always -1 tokens (`first_in`).
    - `sh` is drawn from always 0 tokens (`sys_held`).
    - `bh` is drawn from always 0 tokens (`sub_held`).
    - `kind` = `(if cont then kind@(r − d) else kd)`.
    - `sb` = `(if cont then sb@(r − d) else (if sub_per_slot = true then subp[slot mod sub_prompts] else pick(subp)))`.
    - `psize` = `(if kind = 0 then size(sp) else (if kind = 1 then size(sb) else 0))`.
    - `sysblk` = `psize div (meta_bytes + chunk_bytes)`.
    - `pheld` = `min((if kind = 0 then sh else (if kind = 1 then bh else 0)) div chunk_tokens, sysblk)`.
    - `ptoks` = `(if cont then prior else (psize mod (meta_bytes + chunk_bytes)) div (chunk_bytes div chunk_tokens)) + (if cont or fi < 0 then inn else fi)`.
    - `stored` = `ptoks div chunk_tokens`.
    - `had` = `(if cont and d ≤ retain then min(stored@(r − d), prior div chunk_tokens) else 0)`.
    - `held` = `(if cont then min(prior, kp@(r − ((r mod d) + 1))) div chunk_tokens else 0)`.
    - `hit` = `had`.
    - `nload` = `(if hit > held then hit − held else 0)`.
    - Phase `warm` while `r < warm`, else `serve`,:
      - Computes for `draw(think)`, no I/O.
      - If `kind = 0`:
        - For `q` from 0 while below `sysblk`:
          - `stat` chunk object `q` of the file holding `sp`.
      - If `kind = 1`:
        - For `q` from 0 while below `sysblk`:
          - `stat` chunk object `q` of the file holding `sb`.
      - For `q` from 0 while below `hit`:
        - `stat` the object of `kv` named by conv = `conv`, k = `q`, ext = `data`.
      - If `stored > had`:
        - `stat` the object of `kv` named by conv = `conv`, k = `had`, ext = `data` (may fail with ENOENT).
      - If `sys_local = false and held = 0 and kind = 0` (false here: skipped):
        - `sysblk − pheld` in parallel, `sk` = 0 onward, joined at the end:
          - `b` is chunk object `pheld + sk` of the file holding `sp`.
          - `open` `b` (RDONLY|CLOEXEC).
          - `fstat` `b`.
          - `ioctl` `b` `TCGETS` (may fail with ENOTTY).
          - `lseek` `b` to 0 from the current position.
          - `read` `b`: 1 MiB (`buf`) at the file position.
          - If `meta_bytes + chunk_bytes > buf` (true here):
            - `read` `b`: 2.0 MiB (`meta_bytes + chunk_bytes − buf`) at the file position.
          - `close` `b`.
      - If `sys_local = false and held = 0 and kind = 1` (false here: skipped):
        - `sysblk − pheld` in parallel, `ak` = 0 onward, joined at the end:
          - `b` is chunk object `pheld + ak` of the file holding `sb`.
          - `open` `b` (RDONLY|CLOEXEC).
          - `fstat` `b`.
          - `ioctl` `b` `TCGETS` (may fail with ENOTTY).
          - `lseek` `b` to 0 from the current position.
          - `read` `b`: 1 MiB (`buf`) at the file position.
          - If `meta_bytes + chunk_bytes > buf` (true here):
            - `read` `b`: 2.0 MiB (`meta_bytes + chunk_bytes − buf`) at the file position.
          - `close` `b`.
      - `nload` in parallel, `lk` = 0 onward, joined at the end:
        - `b` is the object of `kv` named by conv = `conv`, k = `held + lk`, ext = `data`.
        - `open` `b` (RDONLY|CLOEXEC).
        - `fstat` `b`.
        - `ioctl` `b` `TCGETS` (may fail with ENOTTY).
        - `lseek` `b` to 0 from the current position.
        - `read` `b`: 1 MiB (`buf`) at the file position.
        - If `meta_bytes + chunk_bytes > buf` (true here):
          - `read` `b`: 2.0 MiB (`meta_bytes + chunk_bytes − buf`) at the file position.
        - `close` `b`.
      - For `s` from 0 while below `⌈(stored − had) / (prefill_step div chunk_tokens)⌉`:
        - Computes for `prefill_per_token × min((stored − had − s × (prefill_step div chunk_tokens)) × chunk_tokens, prefill_step)`, no I/O.
        - For `k` from `had + s × (prefill_step div chunk_tokens)` while below `min(stored, had + (s + 1) × (prefill_step div chunk_tokens))`:
          - `t` is the object of `kv` named by conv = `conv`, k = `k`, ext = `tmp`.
          - `open` `t` (WRONLY|CREAT|TRUNC|CLOEXEC).
          - `fstat` `t`.
          - `ioctl` `t` `TCGETS` (may fail with ENOTTY).
          - `lseek` `t` to 0 from the current position.
          - `write` `t`: 28 bytes (`meta_bytes`) at the file position.
          - `write` `t`: 3 MiB (`chunk_bytes`) at the file position.
          - `close` `t`.
          - `rename` `t` to the object of `kv` named by conv = `conv`, k = `k`, ext = `data`.
      - Computes for `decode_per_token × out`, no I/O.
