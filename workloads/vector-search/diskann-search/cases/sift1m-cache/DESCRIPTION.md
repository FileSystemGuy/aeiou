Beam search over a sector-packed graph index: dependent rounds of `beam` concurrent 4 KiB reads per query. In the catalog it is `vector-search/diskann-search`: application `diskann`, format `diskann-index`, phase inference, domain ai. An example case (`sift1m-cache`: vectors data), its parameters holding at 1 GPU. Traced: a capture is within the tolerances. `index` holds 200,001 samples, slots of one file (781.3 MiB in 1 file), looked up by id; sizes always 4 KiB. `pq` holds 1 sample, one a file (30.5 MiB in 1 file), looked up by id; sizes always 30.5 MiB.
